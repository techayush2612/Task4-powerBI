# Task 4: Dashboard Design – Sales Analytics

## 📌 Project Overview
This project is part of the Data Analyst Internship at Elevate Labs. The objective is to design an interactive Power BI dashboard to analyze sales performance and provide meaningful business insights.

## 🎯 Objective
To create an interactive dashboard that helps business stakeholders understand sales, profit, orders, and business performance through visualizations and KPIs.

## 🛠️ Tools & Technologies Used
- Microsoft Power BI
- Superstore Sales Dataset
- Power Query (Data Cleaning & Transformation)

## 📊 Dashboard Features

### 1. Overview Dashboard
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity KPI
- Monthly Sales & Profit Trend
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Top 5 Sub-Categories by Sales

### 2. Detailed Analysis
A separate page for detailed business performance analysis using interactive visualizations and filters.

### 3. Navigation
- Overview
- Detailed Analysis

## 📈 Key Concepts Implemented
- KPI Cards
- Interactive Visualizations
- Line Chart
- Donut Chart
- Column Chart
- Bar Chart
- Data Filtering
- Time-Series Analysis
- Dashboard Navigation

## 📂 Project Files
- Dataset – Sales dataset used for analysis.
- Power BI Dashboard (.pbix) – Interactive dashboard file.
- Screenshots – Dashboard visualizations.
- PPT Summary – Project overview and key insights.
- README.md – Project documentation.

## 💡 Outcome
Successfully designed an interactive Sales Analytics Dashboard using Power BI to visualize business performance and support data-driven decision-making.
